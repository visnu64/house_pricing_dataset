Objective:
Developed a machine learning model to predict house prices using the Kaggle "House Prices: Advanced Regression Techniques" dataset.

Key Contributions:

Exploratory Data Analysis (EDA): Identified trends, distributions, and correlations among housing features.

Feature Engineering: Created new variables (e.g., house age, total living area) and handled missing data to enhance model accuracy.

Feature Selection: Used correlation analysis and model-based techniques to retain the most predictive features.

Modeling: Trained and compared multiple algorithms, including:
Linear Regression
Random Forest
XGBoost

Evaluation: Assessed models using metrics like Mean Absolute Error; selected the best-performing model for final predictions.

Insights: Discovered key factors influencing house prices, such as overall quality, location, and total square footage.
